# TaskFlow – Modern To-Do List

TaskFlow is a simple web-based task management application built using **HTML, CSS, and JavaScript**. It helps users organize and manage daily tasks efficiently.

## Features

* Add, edit, and delete tasks
* Mark tasks as completed
* Set priority and category
* Add due dates
* Search, filter, and sort tasks
* Dark/Light mode
* Task progress and statistics
* Local Storage for saving tasks

## Technologies

* HTML5
* CSS3
* JavaScript
* Git & GitHub
* GitHub Actions
* GitHub Pages

## DevOps Workflow

```text
Develop → Test → Commit → GitHub → CI → Fix Errors → Deploy
```

GitHub Actions automatically checks the project whenever changes are pushed to the `main` branch.
